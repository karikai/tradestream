# **App Name**: TradeStream

## Core Features:

- Live Trade Feed: Display real-time stock options trades in a Twitter-like feed format.
- User Following: Allow users to follow specific traders and receive updates in their personalized feed.
- Filtering & Search: Enable users to filter trades by stock ticker, option type (calls/puts), and expiration date.
- Trade Details: Provide detailed information for each trade, including size, price, and timestamp.
- Sentiment Analysis Tool: Use AI to determine the overall sentiment (bullish/bearish) surrounding a particular stock or option based on the trades being made. This is a tool available to subscribers, offering another signal of market movement.

## Style Guidelines:

- Primary color: Deep Indigo (#3F51B5) for a sense of financial seriousness and trust.
- Background color: Light gray (#F0F0F0) to ensure readability and a clean interface.
- Accent color: Electric Green (#7CFC00) to highlight key information like price increases or profitable trades.
- Body and headline font: 'Inter', a grotesque-style sans-serif, will be used for both headlines and body text, creating a modern, machined, objective, neutral look.
- Use simple, crisp icons to represent different asset classes, trade types, and filter options.
- Implement a clear, single-column layout similar to Twitter to facilitate easy consumption of the trade feed.
- Subtle animations to indicate new trades and changes in trade prices.
